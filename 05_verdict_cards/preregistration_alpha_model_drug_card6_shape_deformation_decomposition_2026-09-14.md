# 预注册：α模型 药物卡6 · 形状变形分解（τ类 vs h_ss类）（2026-09-14）

判线跑前钉死，跑后不动。本卡是**归因卡**：卡5 已否掉纯阻断（中位 ε_x=0.088，30/30 药全超线），本卡把每个单元的形状变形总量分解成**时间尺度型**（τ 类：药物改变去激活/恢复速率，Ramp 窗内形状沿时间轴伸缩）与**幅度形状型**（h_ss 类：药物改变各电压稳态占据/失活，时间轴不动幅度形状变），为 Stage B 药物模块设计定路线。

## 一、问题

卡5 的 ε_x 是变形总量，没有回答"药物动了哪张表"。DeepSeek 审计建议的三分解（τ/h_ss/G）修正为两分解：G 是纯缩放（不产生形状变化，已在 b_ss 账上）；单 Ramp 窗内 τ_m 与 τ_h 不可分（一起伸缩），故只分**时间尺度成分**与**幅度形状成分**。

## 二、数据

同卡5 逐字：CiPA 全药库 `a6k5t` 全部 `hERG*` 数据集，`subtracted\ted\ted.xlsx`（游标单位换算 v3 修复同用）+ 逐细胞原始 csv。

## 三、单元与守门（与卡5 逐字相同，钉死）

分析单元 = 细胞 × 药物浓度段；|A_ctrl| ≥ 50 pA；0.2 ≤ b_ss ≤ 0.9；段扫 ≥ 5；每数据集 ≤3 细胞（|A_ctrl| 距中位近优先，冒烟 1 细胞）。单元选择全程确定性（无随机），应与卡5 单元集合逐字一致——**回归检查**：本卡 ε_x0_full 与卡5 单元表逐单元比对，最大绝对差 < 1e-9 判管线复现过。

## 四、分解指标（钉死）

每单元：对照/药物段基线减除 → 扫平均 → Ramp 窗 [r0, r1] 内各自峰幅度归一（cn, dn，全程与卡5 同口径）。

1. **ε_x0_full**：卡5 原口径 ε_x（全 Ramp 窗，噪声地板扣除），回归检查用。
2. **κ* 配准**：κ 网格 [0.5, 2.0] 步 0.02（76 点，含 1.0）。对每个 κ，比较域 D(κ) = [max(r0, r0/κ), min(r1, r1/κ)]（两侧都只取 Ramp 窗内样本，不越界）；dq(t)=dn(κ·t)、cq(t)=cn(t) 在 D(κ) 上各自重新归一，ε(κ)=RMS(dq−cq)/RMS(cq)。κ* = argmin ε(κ)。
3. **同域对**：在 D(κ*) 上算 ε(1) 与 ε(κ*)；ε_noise 同卡5 公式（Baseline 窗 σ 与 Ramp 窗峰幅度，伸缩不变）；ε_x1 = sqrt(max(ε(κ*)²−ε_noise²,0))（warp 后残差），ε_x0_sd = sqrt(max(ε(1)²−ε_noise²,0))。
4. **f_τ** = max(0, 1 − (ε_x1/ε_x0_sd)²)（时间尺度解释的方差份额）；ε_x0_sd ≤ 1e-6 → f_τ = NaN。**判-able 门槛**：ε_x0_full ≥ 0.03（卡5 ε_x_thr 在案值）的单元 f_τ 才入判。
5. **逐细胞对照地板 f_τ_cc**：同细胞对照段奇/偶扫均值对（≥4 对照扫）走同一 warp_fit（无门槛，原始 f_τ）——真实噪声/非平稳下的配准过拟合地板。
6. 网格触边（κ*=0.5 或 2.0）逐单元登记。

## 五、合成自检（判线由对照自动锚定，钉死）

模板 = 首个合格单元数据集的真实对照均值波形（find_template，循环前一次）：

- **C1 纯缩放**（×0.5 + 实测级 AR(1) 噪声，20 重复）：κ*∈[0.95, 1.05] 须 20/20（无伪时间配准）；C1 原始 f_τ 中位登记为合成地板参照；
- **C2 时间拉伸**（Ramp 窗全窗均匀 ×1.25 + 噪声，20 重复）：κ*∈[1.15, 1.35] ≥18/20 且 f_τ ≥ 0.8 ≥18/20（τ 类变形被识别且吃净）；
- **C3 幅度变形**（峰后幅度线性渐缩至 ×0.75，时间不动 + 噪声，20 重复）：κ*∈[0.95, 1.05] ≥18/20 且中位 f_τ ≤ 0.5（幅度变形不被伪装成 τ）。

自检不过 → 全卡降级登记。

## 六、判线（跑前钉死）

细胞级配对：每细胞取判-able 单元中位 f_τ，与同细胞 f_τ_cc 配对（Δf_τ = 药 − cc）。

- **T1（时间尺度成分显著）**：Wilcoxon 符号秩单侧 p < 0.01（方向：药 > cc）**且** 中位 Δf_τ ≥ 0.25；
- **T2（warp 后残差仍超线）**：判-able 单元中位 ε_x1 > 0.03；
- **总判 2×2**：T1∧¬T2 → **τ 主导**（Stage B 药物模块走 τ 表调制）；¬T1∧T2 → **幅度形状主导**（走 h_ss 表调制）；T1∧T2 → **双成分**（模块需两条腿）；¬T1∧¬T2 → 变形低于可判水平（与卡5 总判并读，登记异常）。
- 配对细胞数 < 10 → 判词降级"不可判"。
- 分药表（中位 κ*、f_τ、ε_x1、n）与 Spearman(κ*, log10 C) 只登记不施压。

## 七、已知限制（跑前声明）

1. 单 Ramp 窗内 τ_m 与 τ_h 不可分，"τ 类"是两者合量；
2. h_ss(V) 平移在 Ramp 窗表现为时间平移（非伸缩），留在幅度残差侧——"幅度形状型"含 h_ss 平移/形变混合；
3. κ 网格分辨率 0.02，域收缩最多损失半窗（κ=2 或 0.5 时仍有 ≥数百样本）；
4. 浓度-时间混淆与卡5 同（递增给药段间漂移），本卡不另解。

## 八、输出

逐单元 JSON/CSV（ε_x0_full、κ*、ε_x1、ε_x0_sd、f_τ、f_τ_cc、ε_noise、b_ss、浓度）+ 分药汇总 + 图（κ* 分布、细胞级 f_τ 药 vs cc 配对散布、ε_x0 vs ε_x1、分药中位）。SMOKE=1 冒烟 3 数据集（dofetilide lab3、pimozide lab4、moxifloxacin PhaseII-lab1，覆盖 ms/s 两游标路径）× 每集 1 细胞，口径与正式跑逐字相同。

## 九、v2 修订（2026-09-14，冒烟两轮后正式跑前，照实登记）

**修订事由（冒烟实证，两轮）**：

1. **第一轮冒烟：C2 未找回（κ* 中位 1.020 vs 真值 1.25，f_τ≈0）**。根因：warp 公式绕时间原点伸缩（dn(κ·t)），而 Ramp 窗起点 r0≈0.835 s 远大于窗宽 ~0.1 s——绕原点伸缩 κ=1.25 等价于 0.167 s 平移，直接把波形推出窗。物理上 ramp 相位从 r0 起算，warp 必须绕 r0。
2. **第二轮冒烟：C3 暴露可分性限制**——纯幅度渐缩（峰后线性缩至 ×0.75，时间不动）被单参数伸缩以 κ*=0.96 吸收掉中位 80% 方差（f_τ=0.799）。**f_τ 单独不能作 τ 证据**；能分清两者的是 κ* 的幅度轴（冒烟实证：C1 纯噪声 κ*=1.000、C3 幅度渐缩 |κ*−1|=0.04、C2 真拉伸 |κ*−1|=0.26，三者干净分开）。

**修订内容（钉死）**：

- §四.2 的 warp 公式与比较域由本修订替换：**dq(t) = dn(r0 + κ·(t − r0))**（绕 r0 伸缩）；**D(κ) = [r0, min(r1, r0+(r1−r0)/κ)]**（κ≤1 全窗，κ>1 右缘收缩，两侧都不出 Ramp 窗）；
- **C3 判线改 κ* 口径**：|κ*−1|≤0.05 ≥18/20（保留原条件）；C3 的 f_τ 转登记，附注"伸缩吸收幅度渐缩"的可分性限制；
- **新增对照锚定阈值 κ_thr = max(3 × C1 中位|κ*−1|, 0.10)**；
- **T1 改双条件**：判-able 单元中位 |κ*−1| ≥ κ_thr **且** 中位 f_τ ≥ 0.5（warp 在显著非 1 的 κ* 处吃掉大部分变形才算 τ 证据）；细胞级 Wilcoxon 配对（Δf_τ vs cc）降为登记；判-able 单元 < 30 → 不可判。T2（中位 ε_x1 > 0.03）与 2×2 总判结构一字不动。

**冒烟复核（修订后，SMOKE=1）**：合成自检过——C1 κ*=1.000（20/20，f_τ 地板 0.000）、C2 κ*=1.260 找回 20/20 且 f_τ=0.998（20/20）、C3 κ*=0.960（20/20 在界内，f_τ=0.799 登记）；κ_thr=0.100。**回归过**：与卡5 冒烟单元表逐单元比对最大 |Δε_x|=6.94e-17，单元集合与 ε_x 逐字复现。

**修订纪律**：只动 warp 实现公式与 T1 的证据轴；分解指标定义（f_τ、ε_x1、判-able 门槛 0.03）、单元守门、2×2 总判结构一字不动。
