## 8. 已否掉清单（前战役判词，本文不重审数字，只登记结论）

## §20 药物卡4：AP 波形下药物阻断的临床风险对拍（2026-09-14 封卷）

**问题（端到端第一级）**：α 模型 + 卡3 参数表，能否在临床游离 Cmax 下分开 CiPA 临床 TdP 风险分级。判线预注册钉死（v2 修订在案：k_off 一致性锚定 k_off=k_on·IC50；主判指标换 S_eq 占空比调整平衡态——冒烟实证慢解离药 105.9 s 远未达平衡，临床慢性给药对应平衡态）。

**设计**：引擎逐字不动 + 捕获型药物模块 dD/dt=k_on·[D]·m·(1−D)−k_off·D；AP 波形（ap_protocol.mat 8.8245 s×12 循环，⟨m⟩=0.256）；主判指标 S_eq = [D]·⟨m⟩/([D]·⟨m⟩+IC50)（解析平衡，kon 消去）；24 药（本库∩CiPA 28：高7/中11/低6），风险标签与游离 Cmax 取 FDA/CiPA 官方 newCiPA.csv（sha256 前16 0045c577ff508bf8 在案）。合成自检三条件（单调/捕获极限/Hill 一致）全过。

**判词（预注册判线逐字执行）**：

- **V1（主判）Spearman ρ(S_eq@1×, 风险序) = 0.475，p=0.0095 → 不过**（判线 ρ≥0.60 且 p<0.01：p 过线、ρ 未达）。
- **V2 AUC(高 vs 低) = 0.810 → 过**（判线 ≥0.80）。
- **总判：分级关联部分成立**——单通道平衡抑制能分"高 vs 低"（81%），三级全排序达不到钉死线。
- 敏感性全同向：锚 IC50 版 ρ=0.467/AUC=0.810；静态 Hill 版 ρ=0.500/AUC=0.810；暂态 84 拍版 ρ=0.332（p=0.056，如 v2 预期弱于平衡态）。成对登记：高vs中 AUC=0.831、**中vs低 AUC=0.591（分界断在这里）**；剔除预先声明三药（sotalol/verapamil/diltiazem）ρ=0.55 仍不达线——缺口不全是三药的事。
- 稳态旗 1/24（ibutilide）；静态退化 9/24（斜率≤0 或档不足，照实登记）。

**失败结构（与预先声明逐条对上）**：高风险组劈叉——ibutilide 0.766 极强，但 sotalol/dofetilide/disopyramide/azimilide 仅 0.030–0.050（Cmax/IC50 边际宽，hERG-only 低估）；低风险 verapamil 0.056/ranolazine 0.069 偏高（CaL 代偿在单通道里缺席）。组中位：高 0.050 / 中 0.026 / 低 0.015。

**机制判读（不遮）**：dofetilide 是标本——Milnes-Hill IC50≈12.6 nM，2 nM 游离 Cmax 经占空比调整只剩 3.9% 抑制，但它是临床头号高风险药。缺口 = **AP 延长反馈闭环**（阻断→平台延长→更多阻断+复极储备下降），固定波形的单通道指标装不下；这正是预注册 Stage B（ORd 宿主 + 六通道，官方 newordherg_qNet.c 已落盘 sha256 前16 eb70fcbc37c94e2d）的存在理由。登记观察：官方动态拟合的 dof hERG IC50=1.46 nM vs Milnes-Hill 12.6 nM 差 ~10 倍——**捕获型强药的 IC50 协议依赖性本身是硬问题**，在案。

## §21 药物卡5：形状不变性判决——纯阻断假设否掉（2026-09-14 封卷）

**问题**：药物模块 I = G·m·h·(1−D)·(V−E) 的核心隐含假设是**纯阻断**——药物只缩放幅度，不动门控 τ（电流形状不变）。本卡用同细胞对照段 vs 各浓度药物段的 Ramp 窗归一化形状直接对拍。判线预注册钉死（v2 修订在案：主指标 ε_x = sqrt(max(ε²−ε_noise²,0)) 噪声地板扣除；v3 修订在案：游标 STIMEU/ETIMEU 单位混杂修复——lab1/lab2=ms、lab3/4/5=s，首轮正式跑 lab1/lab2 全空即此 bug，用户中止作废，修复后复冒烟过）。

**池**：全药库 136/136 数据集全出合格单元（每数据集 ≤3 细胞，|A_ctrl|≥50 pA、0.2≤b_ss≤0.9、段扫≥5），合格单元 **517**（30 条目 = 28 药 + 2 盲法重复）。

**合成自检（单次执行，过）**：C1 纯缩放 ε_x 中位 0.0017 全过；C2 峰后时间拉伸 ×1.2 ε_x 中位 0.2357 全被抓；ε_x_thr = 0.0300（对照锚定）——估计器对 0.03 级变形有分辨力。

**判词（预注册判线逐字执行）**：

- **G1：中位 ε_x = 0.0883 > ε_x_thr 0.030 → 不过**（超线 ~3 倍；噪声地板 ε_noise 中位 0.0043，信号是地板的 20 倍，非噪声误判）。
- **G2：Spearman ρ(ε_x, log10 C) = 0.387，单侧 p = 3.1e-20 → 有漂移**（变形随浓度增大）。
- **总判：纯阻断假设否掉（按药/段定位责任）**。
- 登记：中位 r_shape = 0.9845（0.98 参考线之上）、中位 ε_raw = 0.0889、对照奇偶分裂 r_cc 中位 0.9995（同段重复性近完美，跨段差异是真信号）。

**稳健性（四条）**：① 合成自检过，估计器能分清纯缩放（0.002 级）与变形（0.24 级）；② 136/136 数据集、517 单元、五实验室全覆盖（ms/s 两条游标路径均通）；③ **30/30 药条目分药中位 ε_x 全部超线**（0.036–0.210），方向 100% 一致，无一家干净；④ 阈值不敏感——即便 ε_x_thr 放宽到 0.05 或 0.08，汇总中位 0.088 也不过，G1 结论不依赖阈值取值。

**分药定位（中位 ε_x）**：变形最重 mexiletine 0.210、ondansetron(_blinded) 0.146/0.147、metoprolol 0.136、diltiazem/clarithromycin/sotalol 0.125 族、ibutilide 0.123、dofetilide 0.116；最干净 vandetanib 0.036、risperidone 0.043、cisapride 0.045、droperidol 0.050。**浓度分层（封卷后补算，登记）**：ε_x 中位随浓度单调升——1–10 nM 带 0.045（阈值 1.5 倍）、10–100 带 0.064、100–1k 带 0.065、1k–10k 带 0.114、10k–100k 带 0.132、100k–1M 带 0.181、>1M 带 0.267；ε_noise 各带平（0.002–0.006）——低浓度带变形最小但仍在阈值之上，且非信噪比假象（低浓度药段近满幅度、ε_noise 贴地板）。初稿"低占位近似成立"表述过宽，照此勘误：**纯阻断在任何浓度带都不成立，变形剂量单调增大**，与状态依赖结合图像自洽。

**诚实登记（不移动判线）**：浓度-时间混淆——协议递增给药，G2 的 ρ=0.387 既兼容"浓度越高变形越大"（门控扰动），也兼容"离对照段时间越久段间慢漂移越大"；r_cc 是同段内指标管不了跨段漂移。拆开两说需要洗脱段或变占空比协议数据，登记为后续卡数据需求。

**与在案结论的关系**：① 与卡1/卡2"两药皆捕获型"自洽——捕获型药结合失活态，部分阻断下通道群失活/去激活平衡被扰动，Ramp 形状改变是应有之义，本卡给捕获机制一条独立旁证；② 卡4 的药物模块恰在纯阻断被否的前提下仍拿到 V2 AUC=0.810——**风险排序对形状扰动不敏感，但单通道定量精度上限被本卡钉死**，Stage B（ORd 宿主+六通道）的升级理由再加一条。

## §22 药物卡6：形状变形分解——幅度形状主导（2026-09-14 封卷）

**问题**：卡5 否掉纯阻断后，变形归因到哪张表——τ 类（时间尺度，Ramp 窗形状伸缩）还是 h_ss 类（幅度形状，时间不伸缩）？结论直接定 Stage B 药物模块路线。判线预注册钉死（v2 修订在案：① warp 公式修绕 r0 伸缩——首轮冒烟绕时间原点、κ=1.25 等价 0.167 s 平移把波形推出窗，C2 未找回；② T1 证据轴换 κ* 幅度——次轮冒烟实证单参数伸缩可吸收平滑幅度渐缩 ~80%，f_τ 单独不作 τ 证据）。

**方法**：卡5 单元逐字复用（**回归过**：517/517 单元逐字一致，ε_x 最大差 9.9e-17）；Ramp 窗归一化形状绕 r0 伸缩配准 κ*（网格 [0.5,2.0] 步 0.02，域 D(κ)=[r0, min(r1, r0+(r1−r0)/κ)] 不越界）；f_τ = 1−(ε_x1/ε_x0_sd)²；判-able 门槛 ε_x0 ≥ 0.03（卡5 在案值）；κ_thr = max(3×C1 中位|κ*−1|, 0.10) 对照锚定。

**合成自检（过）**：C1 纯缩放 κ*=1.000（20/20，f_τ 地板 0.000）；C2 时间拉伸 ×1.25 找回 κ*=1.260、f_τ=0.997（20/20）；C3 幅度渐缩 κ*=0.980 在界内（20/20，f_τ=0.737 登记）；κ_thr=0.100。

**判词（预注册判线逐字执行）**：

- **T1 不过**：判-able 440 单元，中位 |κ*−1| = **0.020** << κ_thr 0.10，中位 f_τ = 0.350 < 0.5——**药物不拉伸 Ramp 形状**（κ* 中位 1.020，网格触边仅 2/517）；
- **T2 过**：中位 ε_x1 = **0.0754** > 0.03——warp 只吃掉图书馆中位变形的 ~15%，残差变形仍在；
- **总判：幅度形状主导——Stage B 药物模块走 h_ss 表调制路线，不走 τ 表。**

**登记（三条有信息量的）**：

- Wilcoxon 配对 Δf_τ 中位 0.346、p=1.4e-54（376 细胞）——药物侧变形高度显著，但全部落在小 κ* 处：正是 C3 型平滑幅度重塑的指纹，不是时间尺度变化；
- Spearman(κ*, log10 C) ρ=0.39、p=2e-17——κ* 随浓度微升（>1 = 略减慢），存在小的剂量相关时间成分，但量级远在判线下（**登记非排除**：残差 ε_x1 内的剂量相关时间成分未做进一步分解，留作后续卡的数据需求）；
- 分药（登记）：τ 样份额最高 tamoxifen（f_τ=0.71）与 sotalol（κ*=1.06、f_τ=0.59，最接近 τ 型仍未越线）；**dofetilide f_τ=0.065、κ*=1.00——变形几乎纯幅度型，warp 完全无用**（pimozide、ibutilide 同纹）；warp 后残差最重 mexiletine ε_x1=0.159、ibutilide 0.116、dofetilide 0.115。

**机制自洽（与卡1/卡2 同图）**：幅度形状主导 = 药物改各电压稳态占据/失活而非动力学速率——捕获型结合（偏好失活态）下，ramp 下行中未结合通道正常恢复（动力学不变）、结合通道不恢复（稳态失活被药物占据）→ 幅度形状变、时间不伸缩。**Stage B 药物模块钉死：D 耦合走 h（h_ss 调制），τ 表不动**；卡4 的 m 耦合版（dD/dt=k_on[D]m(1−D)−k_off·D）保留为 V2 已过的历史件。
