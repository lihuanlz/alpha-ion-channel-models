# 预注册 · Nα药 · Nav1.5 药物形状调制判决

**日期**：2026-09-15 ｜ **版本**：v1.0（正式跑前钉死） ｜ **状态**：数据下载中，待冒烟

**问题（三线一致性最后一环）**：Nav1.5 的药物作用是否和 hERG（卡5/卡6）、CaV1.2（Cα-5 判1/判2）同构——**不是纯阻断，而是幅度型形状调制（改 h_ss 不改 τ）**？

**数据源**：Tran et al. 2020, PLOS ONE 15(11): e0241362（FDA Wendy Wu 实验室，与 Ren 2022 CaV 数据同实验室）；OSF https://osf.io/tjuev ，本机落盘 `04_细胞线4\数据\nav15_drug_tjuev\`。

## 二、协议 epoch 图（实测 abf 钉死，非论文转述）

单 sweep 12.5 s：

| 时段 (ms) | 电压 | 用途 |
|---|---|---|
| 0–245 | −95 mV | 保持/基线（基线窗取 10–230 ms） |
| 245–445 | −120 mV | 恢复预脉冲；R_input 测量（−95→−120，Δ25 mV） |
| 445–485 | −15 mV | **INaP 测量窗**（峰在阶跃后 ~0.4 ms） |
| 485–690 | +40 mV | 失活驱动段 |
| 690–785 | 斜坡 +40→−95（−1.35 V/s） | **INaL 测量窗**（斜坡内向峰） |
| 785–12500 | −95 mV | 恢复 |

**侦察结论（决定判3 设计，已实测）**：INa_P 细胞内——斜坡窗电流 −8~−14 pA ≈ 噪声（sd ~8 pA），不可用；−15 脉冲末段残余为外向（+80~+120 pA），被外向电流污染，不可用。**INa_P 组内无干净的失活态池 → 判3 走 INa_L 组内配对 + 跨组对拍**（见 §五）。

## 三、测量口径（对齐论文 Methods）

- **INaP 幅度** = −15 窗（445.2–450 ms）最小电流 − 基线（10–230 ms 均值）；每条件**末 5 迹**平均。
- **INaL 幅度** = 斜坡窗（692–783 ms）最小电流，先减 Ipassive：由 −95/−120 两点 (V, I_mean) 直线外推 Ipassive(V)；每条件末 5 迹平均。
- **INa_L 组阶跃峰**：同 INaP 口径（ATX 细胞内 −15 峰）。
- 波形（判1/判2 用）：445–465 ms（20 ms，覆盖峰+失活衰减），按 |峰| 归一。
- 条件末 5 迹不足 5 时取末 ≥3；<3 该条件作废。

## 四、质量门（自动 + 备注表交叉）

细胞剔除：对照段峰 CV>0.15；对照 |峰|<500 pA；R_input 超出 50–500 MΩ；总览表备注含 died/lost clamp/unstable；sweeps 不足。TTX 残余 >15%（论文 10% 水平）者登记但不剔除（泄漏个体差异）。

## 五、四判（判线跑前钉死）

**对照（先做，不过则全卡作废）**
- C1 合成自检：已知纯幅度缩放波形 → ε_x≈0（<0.01）；已知 τ 变形 → κ* 符号幅度回收（误差<20%）。
- Null-A（噪声地板）：对照段逐迹自助 → ε_x 噪声分布。
- Null-B（对照漂移）：每细胞对照前半 vs 后半波形 → ε_x 零分布；阈值 Q95(Null-B) 全细胞汇总计算。

**判1 · 纯阻断 vs 形状调制（INa_P 组）**
- 池：阻断分数 f≥0.15 的药物条件（f 以同细胞对照末5迹为参照；低占位 f<0.15 条件单独登记，不进主池——hERG 卡5 已示低占位下纯阻断近似成立）。
- 判线：**ε_x 中位 > Q95(Null-B)** 且 **≥70% 条件超自身 Null-B 带**（Wilcoxon 配对 p<0.01）→ 纯阻断否掉。
- 反向：ε_x 中位 ≤ Q95 → 纯阻断在 Nav 成立（与 hERG/CaV 不同，如实登记）。

**判2 · 幅度型 vs 时间型（INa_P 组，同池）**
- warp 检验：药物波形对同细胞对照波形做单参数时间伸缩 κ。
- 判线：**|κ*| 中位 < 0.10** → 幅度型（h_ss 调制，与卡6/Cα-5 同构）；≥0.10 → 时间型（改 τ，三线不同构，登记）。
- 描述性附属：衰减段单/双指数 τ_fit 变化（不判）。

**判3 · 组分依赖（INa_L 组内配对为主）**
- (a) 主判：INa_L 细胞内同 sweep 配对——阶跃峰阻断分数 f_step vs 斜坡峰阻断分数 f_ramp；Δf = f_ramp − f_step。
- 判线：**|Δf| 中位 > Q95(Null-B 的 Δf 零分布)** 且 Wilcoxon p<0.01 → 组分依赖存在。**方向不预设**（Cα-5 判3 教训：条文中性化，解释留判词卡）。
- (b) 附属跨组对拍：每药匹配浓度下 INa_P 峰阻断 vs INa_L 斜坡阻断（非配对，不同细胞集），与论文 IC50 比值对照：methadone 4.7×、norbu 2.0×、bup 1.6×、naloxone 1.6×、naltrexone 0.94×（INaL 更敏感者为 >1）。
- 登记：INa_L 组含 150 nM ATX-II（失活被拖慢），判3 解释为"瞬态组分 vs 抗失活晚组分的差异阻断"，不直接等同经典状态依赖。

**判4 · 外部对拍（论文 Table 1，已抄录备案）**

| 药 | INaP IC50 μM (nH) | INaL IC50 μM (nH) |
|---|---|---|
| Buprenorphine | 31.4±5.7 (1.1) | 19.4±0.5 (1.0) |
| Norbuprenorphine | 8.0±0.7 (1.0) | 4.0±0.5 (1.1) |
| Methadone | 40.1±3.6 (1.3) | 8.5±0.6 (0.9) |

- 我方按药按电流汇总浓度-阻断，Hill 拟合（上下限固定 0/1）得 IC50。
- 判线：10 个 药×电流 对比中 **≥8 个落在论文值 ±50%（1.5 倍）内**。

## 六、总判逻辑

- 判1 ✓ + 判2 幅度型 → **Nav1.5 与 hERG/CaV1.2 三线同构**（药物模块统一走 h_ss 调制、τ 表不动）。
- 判1 ✗（纯阻断成立）或 判2 时间型 → Nav1.5 为通道特异差异，如实登记进三线总览。
- 判3/判4 为机制与外部有效性支撑，不单独决定总判。

## 七、已知限制（跑前登记）

1. 数据集无溶剂对照细胞 → 漂移零分布只能来自细胞内对照段（Null-B），TTX 段提供全阻断锚。
2. INa_P 与 INa_L 为不同细胞集，跨组比较非配对。
3. 部分细胞记录跨多 .abf，sweep 编号按文件序拼接后全局索引（冒烟时以 TTX 段峰≈0 验证拼接正确性）。
4. 阿片类药物非经典使用依赖阻断剂，多数浓度阻断弱；判1 主池只含 f≥0.15 条件，统计功效已据此设计。
5. methadone INa_L 组为单浓度多细胞设计（0.3/1/3/10 μM 每细胞一个），剂量反应跨细胞汇总。

## 修订 v1.1（2026-09-15，冒烟发现，正式跑前生效）

**发现**：−15 mV 阶跃 onset 存在**单采样点电容伪影**（445.35 ms 附近，伪影带 445.2–445.5 ms），且幅度**随记录时间持续增长**（实测四文件：首迹 −0.2~−1.0 nA → 末迹 −3.8~−7.5 nA，疑密封退化所致）。后果：药物/TTX 段真峰被阻断后，伪影成为测量窗内主导"峰"（TTX 残余读出 131%，10 µM 段读出负阻断），口径报废。

**修订（测量口径 §三 的三处 + 一处显示）**：

1. **INaP 峰窗**：445.2–450 ms → **445.5–450 ms**（排除伪影带；真峰稳定在 ~445.7 ms，四文件核实）。
2. **形状比较域 WF**：445–465 ms → **445.5–465.5 ms**（同因），波形与峰一律先经 **3 点中值滤波** 再取 min/归一——真峰 2–3 采样宽，幅度损 ~6%，跨条件系统一致，比值（阻断分数）不受影响；单点伪迹被灭。
3. v_check 显示窗改 460–480 ms 平台（原窗含电压沉降期，−20 mV 读数为沉降平均，纯显示问题；台阶实为 −15 mV 已核实）。
4. RAMP 窗与 Ipassive 口径不变。

**备案数据**：伪影带漂移实测（methadone 18605000：sw1 −206 pA → sw85 −7542 pA；naloxone 18818004：sw1 −991 → sw71 −6115；buprenorphine 2018_04_09_0005：sw1 −214 → sw77 −3782；INa_L methadone 18525003：sw1 −958 → sw67 −4430）。

## 修订 v1.2（2026-09-15，静态清点发现，正式跑前生效；**不改主判，只加敏感性臂**）

**发现**：115 细胞行静态清点——备注闸（§四 "备注含 died/lost clamp/unstable 剔除"）剔 27 行（23%）。但其中多数备注为**"全部药物条件完成之后"的事件**（如 "Cell died during TTX application"——TTX 在最末段；又如 "Cell died during 2nd concentration application"——只损 c2）。v1.0 粗闸把这些细胞完好条件下的数据一并丢弃。

**修订（双臂设计）**：

- **主判臂 = v1.0 粗闸，不动**。判 1–4 以主判臂为准。
- **敏感性臂 = 精细备注闸**：从备注解析坏事件起始 sweep（TTX 段死亡→坏点=TTX 区间起点；"2nd concentration"→c2 起点；显式 sweep 号→该号；无法定位→保守剔除），**坏事件起点及之后所在条件作废，之前的条件保留使用**（对照段受损则整细胞剔除，不变）。
- **判读纪律**：两臂判词一致 → 主判结论稳健，登记两臂；不一致 → 以 v1.0 主判臂为准并显式登记分歧，提交审计，不追溯改闸。

**静态清点备案**：27 行备注明细已存档（正式跑 JSON 的 excluded 字段）；88/115 静态可跑（其余数据门 CV/峰/R_in 在跑时判定）。
