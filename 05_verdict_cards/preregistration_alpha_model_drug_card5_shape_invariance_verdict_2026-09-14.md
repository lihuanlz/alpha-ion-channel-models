# 预注册：α模型 药物卡5 · 形状不变性判决（2026-09-14）

判线跑前钉死，跑后不动。本卡是**假设判决卡**：检验药物模块的核心隐含假设——**纯阻断（药物只缩放幅度，不动门控时间常数/电流形状）**。

## 一、问题

卡4 药物模块 I = G·m·h·(1−D)·(V−E) 假设未结合通道的四表 τ 不被药物扰动。若某药改变门控动力学（如减慢去激活），部分阻断下的电流会**变形**而非仅缩放。本卡用同一细胞的对照段 vs 各浓度药物段直接比形状。

## 二、数据

CiPA 全药库 `a6k5t` 全部 `hERG*` 数据集（结构同卡3）。每数据集读 `subtracted\ted\ted.xlsx`（LiquidAdditions 取对照/药物段 ANL 扫号与浓度、CursorsDefinitions 取 Baseline/Ramp 时间窗）+ 逐细胞原始 csv（`subtracted\ted\{CELLID}.csv[.zip]`，trace_#N_current/_voltage 列，t_ms 时间轴）。缺 raw csv 的数据集登记"raw缺"跳过（lab5 原生缺口预期在此显现）。

## 三、单元与守门（钉死）

- 分析单元 = 细胞 × 药物浓度段。每数据集最多取 3 个细胞（按 |A_ctrl| 距中位最近优先），每细胞对照段末 5 扫 vs 各浓度段末 5 扫。
- 单元合格门槛：|A_ctrl| ≥ 50 pA（卡3 v2 单位归一规则同用）且 0.2 ≤ b_ss ≤ 0.9（b 太低无检验力，太高药段只剩噪声）且段内扫数 ≥ 5。

## 四、形状指标（钉死）

每单元：对照/药物段各自基线减除（Baseline 窗）→ 扫平均 → **Ramp 窗**内按各自峰幅度归一 →

- r_shape = 归一化药物形状 vs 对照形状的 Pearson 相关（Ramp 窗全程）；
- ε = RMS(药_norm − 对照_norm) / RMS(对照_norm)（Ramp 窗）。

诊断登记（不入判）：对照段奇/偶扫分裂的形状相关 r_cc（噪声地板）；b_ss；浓度。

## 五、合成自检（跑前钉死，判线由对照自动锚定）

取冒烟数据集真实对照平均波形做模板：
- C1 纯缩放（×0.5 + 实测级 AR(1) 噪声，20 重复）：必须全过（r ≥ 0.98 且 ε ≤ ε_thr）；
- C2 门控变形（峰后时间轴 ×1.2 拉伸，模拟去激活减慢类变形，20 重复）：必须全被抓（r < 0.98 或 ε > ε_thr）；
- ε_thr = max(3 × C1 中位 ε, 0.05)。
自检不过 → 全卡降级登记。

## 六、判线（跑前钉死）

- **主判 G1**：全库汇总（合格单元）中位 r_shape ≥ 0.98 **且** 中位 ε ≤ ε_thr → 形状不变过。
- **G2 浓度漂移**：Spearman(ε, log10 浓度)，ρ>0 且单侧 p < 0.01 → "有漂移"（gating 扰动证据）；否则 "无漂移"。
- **总判**：G1∧G2 → **纯阻断假设封卷**；G1 过、G2 不过 → 部分成立（总体不变但有浓度相关变形，定位到药/档登记）；G1 不过 → 纯阻断否掉，按药/段定位责任。
- 分药中位表只登记不施压。

## 七、输出

逐单元 JSON（r_shape/ε/b_ss/浓度/r_cc）+ 分药汇总 CSV + 图（r_shape/ε 分布 vs 对照地板、ε~浓度散布）。

SMOKE=1 冒烟：3 数据集（dofetilide lab3、pimozide lab4、moxifloxacin lab1）× 每集 1 细胞 + 合成自检，口径与正式跑逐字相同。

## 八、v2 修订（2026-09-14，冒烟后正式跑前，照实登记）

**修订事由（冒烟实证）**：首轮冒烟中 dofetilide lab3 单元 r_shape=0.967 < 0.98 线，但该单元噪声地板 r_cc=0.9997——药段幅度被阻断压小（b 越大信噪比越差），绝对 r 线对高阻断单元不公平，会把噪声误判成形状变形。冒烟 n=2 不足以下判词，但统计缺陷必须在正式跑前修掉。

**修订内容（钉死）**：逐单元噪声地板扣除。

- 每单元加测 ε_noise = sqrt(σ_d²/A_d² + σ_c²/A_c²)（σ = 各组平均波形在 Baseline 窗的标准差，A = Ramp 窗峰幅度）；
- 主指标改 **超额形状残差 ε_x = sqrt(max(ε² − ε_noise², 0))**（纯噪声部分扣除后的真变形）；
- ε_x_thr = max(3 × C1 中位 ε_x, 0.03)（对照锚定）；合成自检相应改：C1 中位 ε_x ≤ ε_x_thr（应≈0），C2 中位 ε_x > ε_x_thr（应≈0.2）；
- **G1 改：汇总中位 ε_x ≤ ε_x_thr → 形状不变过**；**G2 改：Spearman(ε_x, log10 浓度) 同口径**；r_shape / r_cc / ε 全部转为登记指标。

**修订纪律**：只动指标的噪声校正，单元门槛、取样规则、Ramp 窗、判线结构（G1∧G2）一字不动。

## 九、v3 修订（2026-09-14，正式跑首轮发现数据解析缺陷，用户中止后修复，照实登记）

**修订事由（正式跑实证）**：首轮正式跑输出异常——合成自检标题反复空刷、lab1/lab2 全部 28 数据集报"单元0 无合格单元"。用户中止运行，该次结果作废。逐数据集实证根因：**ted.xlsx 的 CursorsDefinitions 游标带 STIMEU/ETIMEU 单位列，lab1/lab2（Phase I 与 II）单位为毫秒（Ramp 窗 800–900 ms），lab3/4/5 为秒（0.835–0.935 s）**。卡5 从卡1 继承的游标解析忽略单位列，把 ms 当秒 → Ramp 窗落在 800–900"秒"（迹线全长仅 ~2 s）→ 形状指标全空 → 单元全灭。卡1 当年只跑 lab3/lab4，故从未踩到。合成自检嵌在数据集循环内、异常被 `except` 吞掉，导致每个空数据集都重试自检并打印空标题（刷屏来源）。实证在案的数据集：lab1 azimilide=ms、lab2 verapamil/azimilide=ms、PhaseII lab1 moxifloxacin=ms、lab2 astemizole=ms；lab3 dofetilide=s、lab4 pimozide=s、lab5 sotalol=s、盲法 lab5 dofetilide=s。

**修订内容（钉死）**：

- 游标解析按 STIMEU/ETIMEU 单位列统一换算为秒（含 "ms" → ÷1000）；
- csv 读取 zipfile 改单句柄（原双开裂句柄）；
- 合成自检抽离数据集循环，`find_template` 顺序扫描取首个合格单元数据集的对照波形，循环前独立跑一次，异常显式打印不再吞没。

**冒烟复核（修复后，SMOKE=1）**：合成自检单次执行且过（C1 ε_x 中位 0.0017 全过、C2 ε_x 中位 0.2357 全被抓、ε_x_thr=0.0300）；三冒烟数据集全部出合格单元——dofetilide lab3 r=0.967/ε_x=0.117、pimozide lab4 r=0.999/ε_x=0.016、**moxifloxacin PhaseII-lab1（ms 游标路径）r=0.952/ε_x=0.114**（修复前 0 单元）。ms/s 两条路径均通。

**修订纪律**：只修数据解析与自检结构，判线（G1 中位 ε_x ≤ ε_x_thr、G2 Spearman 漂移、总判三分支）、单元门槛、指标定义一字不动。
