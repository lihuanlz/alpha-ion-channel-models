# 预注册 Cα-3：CDI 结构形式判决——新增快分量 vs 整体加速（跑前钉死 v1.0）

**日期**：2026-09-15 · **状态**：v1.0 跑前钉死 · **承继**：Cα-1（CDI 存在且恒定，Δf=0.293）；Cα-2（微域幅度分级未获支持 → CDI 为幅度不敏感的恒定增量）· **数据**：同 Cα-1/2（0016 登记剔除主判）

---

## 一、问题

Cα-1/2 把 CDI 钉成"分载子的恒定增量"。本卡问它的**动力学结构形式**——两种互斥候选：

- **H-add（新增快分量）**：Ca²⁺ 迹线 = Ba²⁺ 迹线形状 + 一个额外快指数分量。可证伪预测：Ca²⁺ 需双指数、其慢分量 τ_slow ≈ Ba²⁺ 的 τ（比 ∈[0.7,1.4]）、快分量权重 w_fast ≈ Δf（0.293 附近）；差值曲线 D(t)=N_Ba−N_Ca 先升后降（两族曲线后段合拢）。
- **H-acc（整体加速）**：Ca²⁺ 迹线 = Ba²⁺ 迹线的时间压缩（warp）。可证伪预测：单指数即足、τ_Ca/τ_Ba < 0.7、D(t) 窗内单调爬升不合拢。

**侦察登记（1/3 抽样，跑前）**：D(t) 从 0 升到 30 ms 处 0.307 且仍在爬升——两种假说在该窗内都可解释（H-add 需 τ_slow 较大、H-acc 直接成立），判别依赖分量分解 + D 形分类联合，不单靠哪一个。

## 二、提取（跑前钉死）

**逐 sweep**（QC 同 Cα-1b：G1′ |V−17|≤8、G2′ 峰≤−300 pA，外加）：
- 峰潜伏 ℓ = 段起点到峰的时间；**ℓ ≤ 15 ms 才入形状池**（保证峰后窗 ≥25 ms，登记每细胞被此门剔除的比例）；
- 归一化峰后迹线 d(t) = I(t)/I_peak，t∈[0, 25 ms]（250 点 @10 kHz，自峰起）。

**逐细胞**：平均迹线 d̄(t)，有效 sweep ≥ 20 入池。
**组曲线**：N_Ca(t)、N_Ba(t) = 细胞平均迹线的等权平均（不用 sweep 池化，防大文件主导）。

## 三、分析与判线（跑前钉死）

**A. 分量数判决（每细胞 + 组曲线）**：单指数 M1（C+A·e^(−t/τ)）vs 双指数 M2（C+A1·e^(−t/τ1)+A2·e^(−t/τ2)），AICc 选型，M2 需胜 >10 才算数。

- **判 1（快分量存在）**：Ca²⁺ 组曲线 M2 胜 M1（AICc 差 >10）且 ≥4/6 Ca²⁺ 细胞个体同为 M2；Ba²⁺ 组为对照登记。
- **判 2（结构形式）**（判 1 过才下）：三条件联合——
  ① τ_slow(Ca)/τ(Ba) ∈ [0.7, 1.4]；
  ② w_fast = A1/(A1+A2) 跨细胞中位 ∈ [0.15, 0.45]（覆盖 Δf=0.293 ± 边际）；
  ③ D(t) 呈回落签名：argmax D < 0.8×窗长 且 D(末) < 0.8×D(max)；
  三条全过 → **判 CDI = 新增快分量（H-add）**；① 不过且 τ_slow/τ_b < 0.7 → 判加速成分混入（H-acc 或混合），登记；判 1 不过 → 直接走 H-acc 支路：登记单指数 τ_Ca/τ_Ba 比与 D 形，判"本窗内 CDI 表现为整体加速"。
- **判 3（恒定）**：w_fast 跨细胞 CV<0.3 且 max/min<2.0 → 快分量权重为恒定家族参数（入模型卡）。
- **降级条款**：若 ≥3 细胞的峰后门（ℓ≤15 ms）通过率 <50%，或两组入池细胞 <3，判词降级为"窗长/潜伏期受限，只登记描述"——不硬判。

**噪声地板**：组曲线残差对照 = 细胞级 bootstrap（1000 次重抽样细胞）给出的 N(t) 逐点 90% 带；拟合残差 RMS 须与该带半宽同报，残差 < 带宽不解释为过拟合证据。

## 四、冒烟（正式跑前自验）

- S1 回收 H-add：合成 w=0.30、τ1=8 ms、τ2=50 ms、C=0.4 迹线 + 实测噪声 → w 回收 |误差|≤0.05、τ_slow 回收 ≤20%、M2 选中 ≥18/20；
- S2 拒绝 H-acc：合成 warp 迹线（τ_Ca=τ_Ba/2）→ M2 不当选 ≥16/20（AICc 不瞎加分量）；
- S3 D 形分类：两族合成各 20 例，回落/单调分类正确 ≥18/20；
- S4 峰潜伏门：合成 ℓ 分布混合 → 门只剔 ℓ>15 ms，误剔率 0/20。
- 冒烟不过，正式跑不开。

## v1.1 修订段（2026-09-15，冒烟驱动，正式跑前登记）

### 触发原因（冒烟实测，非数据窥视）

v1.0 的自由双指数 M2 在 25 ms 窗 + 细胞级噪声（σ≈0.003）下**截断简并坐实**：τ_slow 与平台 C 互吸，w 回收中位偏差 −0.12、τ₂ 偏差 −46%；且 D 形分类器理论死穴——τ_slow≳40 ms 时回落签名在 25 ms 窗内物理上发展不出来（D 峰值位于窗外），两类合成家族分类仅 10/20（随机水平）。**v1.0 的判 1/判 2③ 在该窗内不可执行**，正式跑前修订。

### v1.1 设计变更（替代判线，跑前钉死）

**核心改动：自由 M2 → 嵌套约束模型**（快时间常数锚定，消截断简并）：

- **H0（加速族）**：d(t) = C + A·e^(−t/τ)（3 参）；
- **H1（新增快分量）**：d(t) = C + A·[(1−w)·e^(−t/τ) + w·e^(−t/τf)]，**τf ≡ 8 ms 锚定**（4 参，慢 τ 与平台两模型共享 → w 由早期曲率单独钉死）。冒烟实测：σ=0.003 下 H1 选中 20/20、w 偏差 −0.009；warp 对照 H1 不当选 20/20。

**替代判线**：

- **判 1′（快分量存在）**：Ca²⁺ 组曲线 H1 胜 H0（AICc 差 >10）且 ≥4/6 Ca²⁺ 细胞个体同胜；Ba²⁺ 组为阴性对照（预期不胜出或 w≈0，登记）。
- **判 2′（H-add vs H-acc）**：判 1′ 过才下——① w_fast 跨细胞中位 ∈ [0.15, 0.45]（覆盖 Δf=0.293）；② H1 慢 τ 的 Ca/Ba 比 ∈ [0.7, 1.4]（VDI 骨架未动）。双过 → **判 CDI = 新增快分量（H-add）**；② 不过且比 <0.7 → VDI 自身亦加速（混合型），登记。
- **判 3′（恒定）**：w_fast 跨细胞 CV<0.3 且 max/min<2.0 → 恒定家族参数。
- **敏感性臂（登记）**：τf ∈ {5, 12} ms 重拟，w 变化 >±0.08 登记为锚定敏感。
- **D 形曲线降级为纯描述**，不再构成判据（理由如上，冒烟在案）。
- v1.0 判 1/判 2/判 3 全文废止，以本段为准；§二提取（峰后门 ℓ≤15 ms、25 ms 窗、组曲线等权）不变。

### v1.1 冒烟（替代 §四，已全过）

## v1.2 修订段（2026-09-15，第二轮冒烟驱动，正式跑前登记；与 v1.1 同日同跑次前）

### 触发原因

v1.1 单锚 τf≡8 ms 的 S3′ 冒烟挂：真值 τf=8 用锚 5 拟合 w 偏移 −0.153（超 ±0.08）——**w 估计对锚点选择敏感，单锚任意性不可接受**。网格选型冒烟同时探出物理边界：**真值 τf≳14 ms 时快分量在 25 ms 窗内与慢分量不可分**（H1 选中仅 1/10）——这是窗长的信息极限，不是估计器病。

### v1.2 设计变更（替代 v1.1 锚定方案，跑前钉死）

- **τf 单锚 → 网格选型**：τf ∈ {4, 6, 8, 12, 16} ms，逐锚 H1 拟合，**全网格 AICc 联合选型**（锚点选择即模型选择一部分）；报告选中 τf 与对应 w。**副产物：每细胞 CDI 快时间常数估计**（登记）。
- **判 1′/判 2′/判 3′ 文字不变**（w 取选中锚之值；判 2′① 区间 [0.15,0.45] 已容纳冒烟实测 −0.08 系统性低估）。
- **可识别性边界登记**：若实测 CDI 快分量 τf ≳ 14 ms，本窗不可分，将落 H0 支路——判词须写明"快分量 τf≳14 ms 时本协议窗不可判"，不硬判。
- **v1.2 冒烟（全部实测在案）**：S1″ τf=8 真值 H1 选中 20/20、w 偏差中位 −0.076（判线改 ≤0.08，低估方向已登记）；S2″ warp 对照 20/20；S3″ τf∈{5,14} 真值：τf=5 选中 10/10 且 w 偏差 −0.016；τf=14 选中 1/10（边界实测入档）；S4 沿用。
