# 预注册 Cα-4：CaV1.2 斜坡 I-V 温度律与反转电位载子判决（跑前钉死 v1.0）

**日期**：2026-09-15 · **状态**：v1.0 跑前钉死 · **承继**：Cα-1/2/3（CDI 存在→恒定增量→新增快分量组水平成立）· **数据**：同 Cα-1（Temperature_Ca2 6 细胞 / Temperature_Ba2 5 细胞，0016 登记剔除主判）

## 一、问题与物理

每 sweep 的下斜坡段（0.60–0.72 s，+47→−63 mV，120 ms）是本数据集白送的**瞬时 I-V**。在斜坡起点通道已完成 +47 mV 失活，斜坡扫过正电压区时通道状态近似冻结 → I(V) = G_eff·(V − E_rev) 在该区**近似线性**：斜率 = G_eff（有效电导），横截距 = E_rev。由此每 sweep 可得 G_eff(T) 与 E_rev(T) 的温度序列，回答两个跑前钉死的问题：

1. **电导温度律**：G_eff 的 Q10 是否跨细胞恒定（文献预期电导 Q10 ≈ 1.3–1.5，扩散限制级）；
2. **E_rev 载子差与恒定性**：Ca²⁺ vs Ba²⁺ 的反转电位差（侦察见 Ba²⁺ ≈ +40 mV、Ca²⁺ > +47 mV），及各组内跨细胞恒定性。

## 二、提取（跑前钉死）

**逐 sweep**：
- 斜坡分析窗：t∈[0.605, 0.715] s 中回读电压 V∈[0, +45] mV 的部分（正电压、通道冻结、驱动力大）；
- **线性拟合 I = a + b·V**：b = G_eff（pA/mV → nA/mV 换算登记），E_rev = −a/b（**外推截距，登记为外推**）；
- 线性度自检 R²（方法自证）；
- QC：G1′′ 该 sweep 主测段过 Cα-1b G1（|V_+17−17|≤8 登记不用，斜坡窗独立——改为：斜坡窗内电压单调下降且覆盖 ≥30 mV 才算有效）；G2′′ 窗内点数 ≥200；G3′′ 线性拟合 R² ≥ 0.98（不满足则该 sweep 登记为"线性近似失败"，不剔细胞只剔 sweep）；浴温 T 同 Cα-1。
- **细胞入池**：有效 sweep ≥ 20 且温度跨度 ≥3 °C、1 °C 分箱 ≥4 箱（同 Cα-1）；0016 登记剔除主判。

**逐细胞**：log₁₀G_eff 对箱中位 T 线性回归 → Q10(G) = 10^(10·m)（G 随 T 升而升，斜率正）；E_rev 逐细胞中位与 IQR（E_rev 预期对 T 弱敏感，斜率登记不判）。

## 三、判线（跑前钉死）

- **判 1（Q10(G) 恒定）**：入池细胞 Q10(G) 跨细胞 CV<0.3 且 max/min<2.0，且每细胞回归 R²≥0.5 → 恒定封卷；否则登记散布。
- **判 2（E_rev 载子差）**：median E_rev(Ba²⁺) < median E_rev(Ca²⁺)，且组间差 bootstrap（10000 次，细胞级）90% CI 不穿 0 → 载子差成立（Ba²⁺ 反转电位更低）。
- **判 3（E_rev 组内恒定）**：各组 E_rev 细胞中位的 SD<5 mV 且极差 <12 mV → 恒定（外推截距噪声大，线从宽，跑前钉死）。
- **登记**：V_peak（ ramp 电流极小点电压，动力学污染区，纯描述）；线性近似失败 sweep 比例；G_eff 绝对水平两组对比（rundown 混杂，只登记）；E_rev(T) 斜率。

## 四、方法边界（跑前登记）

1. 斜坡 120 ms 相对部分动力学不算瞬时：负电压区有去激活/恢复再平衡——**故只用 [0,+45] mV 区**，该限制已写进提取；
2. E_rev 为外推截距（Ca²⁺ 组多数不 bracket 零交叉），系统偏差方向由冒烟标定；
3. G_eff 含失活后剩余可用度（不是 G_max），绝对值不解释为通道数；**Q10(G) 的有效性前提是失活程度的温度依赖小**——此前提由 Cα-1 τ 温度律弱（f_inact 温度斜率 ≈0，Cα-2 控幅度后登记）间接支持，登记为桥。

## 五、冒烟（正式跑前自验）

- S1 回收：合成斜坡 I(V)=G(T)·(V−E_rev)，G(T) 按 Q10=1.4、E_rev=+42、加噪声与轻微负电压下垂 → G 回收 ≤10%、E_rev 偏差 ≤2 mV、Q10 回收 ≤15%；
- S2 线性自检：同合成 R²≥0.98 通过率 ≥19/20；强加非线性（下垂 ×3）→ 检出率 ≥16/20；
- S3 零 Q10：Q10=1.0 合成 → 回收 Q10∈[0.9,1.1] ≥18/20。
- 冒烟不过，正式跑不开。

## v1.2 修订段（2026-09-15，正式跑数据驱动，重跑前登记）

**触发（v1.1 正式跑实测，JSON 在案）**：斜坡电流峰（Ba²⁺ V_pk≈+3、Ca²⁺ V_pk≈+19，文件坐标）落在 v1.0 分析窗 [0,+45] 内部 → I-V 成拱 → |t_c|<3 线性门几乎全灭（Ca²⁺ 六文件合计 0 有效入池；Ba²⁺ 仅登记剔除细胞 0016 过 152 sweep——其钳位异常致峰涂抹出窗，反成唯一"通过"者，佐证该窗测的是伪影）。§一"正电压区通道冻结"前提在峰以下不成立。两项诊断（在案）：① 论文式 Ipassive 漏电减法对通过率零救援（0008/0005/0004/8007 减法前后均 0 过）→ 非漏电问题；② 自适应上肢窗 [V_pk+5,+45] 救回 Ba²⁺（E_rev +42.8~+48.0，组内 SD≈2）但 Ca²⁺ 仍灭——E_rev≈+63 远在窗顶之上，上肢 GHK 曲率真实存在，|t_c| 门正确检出、不可强过。

**变更（三处）**：
1. **G_eff 改弦电导**：逐 sweep 在 V∈[−10,+48] 找斜坡电流极小点 V_pk（5 点滑动平均），QC1 要求 V_pk ≤ +25（保证弦窗在上肢）；G_eff = (I(+45)−I(+30))/15（±1 mV 邻域中位取值，各 ≥10 点），QC2 要求 G_eff>0。**取消 |t_c| 线性门**（弦口径不需要）。
2. **E_rev 统一为 E_chord = 45 − I(+45)/G_eff**，双解释登记：Ba²⁺ 零交叉在弦窗内 → 插值级（冒烟 S4a 对上肢体线拟合交叉验证 ±3 mV）；Ca²⁺ 零交叉在窗顶之上 → **经验下界**（措辞勘正：原写"严格下界"；机制为弦窗内激活上升 + 窗顶以上 GHK 平坦化共致的 S 形 I-V，冒烟 S4b 标定外推系统性偏低 ≈5–16 mV，方向恒定）。
3. **判 2/判 3 落在 E_chord**：判 2 = median E_chord(Ba²⁺) < median E_chord(Ca²⁺) 且 bootstrap（10000，细胞级）90% CI 不穿 0 → 载子差成立（因 Ca²⁺ 真值高于下界，此判对偏差为保守方向）；判 3 = 各组 E_chord 细胞中位 SD<5 mV 且极差 <12 mV（Ca²⁺ 组含表型异质，不过线则登记散布，不反证）。

**判 1 不变**（Q10(G) 跨细胞 CV<0.3 且 max/min<2.0 且每细胞回归 R²≥0.5 → 恒定封卷；否则登记散布）。入池门槛不变（有效 sweep ≥20、1°C 分箱 ≥4、跨度 ≥3°C）。0016 登记剔除主判不变。
