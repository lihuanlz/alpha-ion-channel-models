# 验证卡：τ_rec 网格量化 · 连续精修复核（2026-09-21）

**触发**：Extended Data Fig. 8c 中 hERG τ_rec 各温度组的数据点呈规整水平条纹（25 °C 组最明显）。
**查明**：`α模型\lei211_TAUH_逐孔.py`（L31–39）用网格搜索提取 τ_rec——tr 在 1–80 ms 取 22 个对数等距点（相邻比 1.232，即 23% 量化步长），td 26 点，PINV 线性解幅度比 SSE。每个细胞的 τ_rec 只能落在 22 个离散值上 → 条纹。
**风险**：封卷的 Q10 = 2.84 / R² = 0.991 由网格化中位数算出，需核验是否被网格分辨率抬高（flattering）。

## 三层核验

### 第 1 层：连续精修 v1（幅度错播种）—— 判定为优化器假象，丢弃

脚本 `verify_tauh_continuous_refit_2026-09-21.py`：网格取 (tr, td) 种子后 scipy least_squares 精修，但幅度种子错用 `seg.max()−seg.min()`（hERG 内向电流为负向，符号相反）。

结果：−140 mV 各温度 SSE 改善中位 −1200% ~ −3200%（拟合恶化 10–30 倍，优化器发散）；精修中位数非单调、CV 爆到 2–3，Q10 ≈ 0.91–0.95 / R² ≈ 0.015。
**判定：误播种导致的假象，不是网格美化的证据。丢弃，留档（JSON `verify_tauh_连续精修_2026-09-21.json`）。**

### 第 2 层：连续精修 v2（正确播种，幅度取网格解）—— 通过

- **Q10：−140 mV 网格 2.83 → 精修 2.26（R² 0.970）；−120 mV 网格 2.85 → 精修 2.89（R² 0.999）。**

### 第 4 节：网格下边缘堆积（删失审计）

| 温度 | −140 mV 落最低 2 档 | −120 mV 落最低 2 档 |
|---|---|---|
| 25 | 0.0% | 0.9% |
| 27 | 1.6% | 0.8% |
| 30 | 0.8% | 0.8% |
| 33 | 3.7% | 0.9% |
| **37** | **55.2%** | 16.2% |

37 °C −140 mV 组 55% 细胞顶在网格地板（1.0/1.23 ms）→ 该组中位数是**删失值**（真值 ≤ 网格值的分布被截断在地板），精修上移 1.23→1.57 ms 是截断解除。删失只会**压平** Q10（2.83→2.26），不可能抬高。25–33 °C 各组堆积 ≤ 3.7%，中位数干净。

## 结论

1. ED8c 条纹 = 22 点对数网格（23% 步长）的提取分辨率，非数据 artefact。
2. **封卷 Q10 = 2.84 不是网格 flattering**：正确精修 2.26–2.89、无模型时钟 2.1–3.8，封卷值在带内；Vandenberg 文献层独立给出 2.60（SI T4 已载）。
3. 37 °C −140 mV 组为分辨率删失（登记）；该点下移使 −140 mV 精修 Q10 降至 2.26，−120 mV 不受影响（2.85→2.89）。
4. v1 误播种假象（Q10 ≈ 0.9）已查明原因并丢弃，双版本脚本与 JSON 均留档。

**回写**：SI v02 的 S2 五温度 Q10 段已补提取分辨率审计句（2026-09-21）。封卷数字一字未动。
