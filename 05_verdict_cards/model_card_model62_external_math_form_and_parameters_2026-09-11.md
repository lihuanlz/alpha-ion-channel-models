## 1 一句话定义

model62 = 官方四态环骨架（F11 2011 血统）+ 激活边双指数化 + 一个负电位门控的并联慢导通（X 件），16 参数（13 自由 + 3 冻结），在 16713003 单细胞四协议上标定。

## 2 状态拓扑

四态环 1–2–3–4–1，状态 3 为开态（O），其余为关闭态（C）。静息（−80 mV）初值 y=(0,0,0,1)，即全部分子在状态 4。

```
        k23
  C2 ⇌⇌⇌⇌ O(3)
k12⇅       ⇅k34
  C1 ⇌⇌⇌⇌ C4
       k41
```

**对边同率约束**（代码实现原文 `k12, k21, k41, k14 = k43, k34, k32, k23`）：

k₁₂ = k₄₃，k₂₁ = k₃₄，k₄₁ = k₃₂，k₁₄ = k₂₃

后果：环积 k₁₂·k₂₃·k₃₄·k₄₁ = k₂₁·k₃₂·k₄₃·k₁₄ 恒成立——细致平衡由构造自动满足，全环只有 **4 条独立速率**。

## 3 数学形式

### 3.1 转移速率（v 单位 mV，速率单位 ms⁻¹）

| 边 | 公式 | 说明 |
|---|---|---|
| k₄₃(v) | P₁·e^{P₂·v} + pf₁·e^{pf₂·v} | **激活边，双指数**（第二分量 = Wang 2013 双电荷系统的数学形） |
| k₃₄(v) | P₃·e^{−P₄·v} | 开态 → 状态4 |
| k₃₂(v) | P₅·e^{P₆·v} | 开态 → 状态2 |
| k₂₃(v) | P₇·e^{−P₈·v} | 状态2 → 开态 |

### 3.2 占用动力学

dy/dt = M(v)·y，y₄ = 1 − y₁ − y₂ − y₃（消元）；v 随协议逐点变化。数值积分：拟合侧 Crank–Nicolson 步进（h = 0.05 ms），验收侧矩阵指数 expm(M·Δt)——双数值通道逐位复算一致。Δt = 0.1 ms。

### 3.3 X 并联慢件

慢门变量 x_s 按指数弛豫追踪其稳态：

- 稳态：x∞(v) = XMAX / (1 + e^{−(v−VH)/KX})
- 时间常数：τ_x(v) = TAU0·α_τ·e^{Z·v}（守卫：τ_x < 0.05 ms 拒算）
- 步进：x_s ← x∞ + (x_s − x∞)·e^{−Δt/τ_x}；初值 x_s(0) = x∞(v₀)
- 负电位门控：g_x(v) = 1 / (1 + e^{(v−GX_MID)/GX_K})——**只在恢复期电位导通**（−120 mV 导通 73%，−90 mV 仅 12%）

### 3.4 总电流

I(v, t) = [ GKr·y₃ + α_amp·ALPHA·x_s·g_x ] · (v − EREV)

两项共用同一反转电位 EREV = −88.33 mV（Nernst 计算值，K_i 130 / K_o 4 mM，21.3 °C，**非拟合**）。

## 6 适用域与已知边界（诚实声明）

1. **sine_wave R² = 0.95404，离自设阈值 0.955 差 0.00096。** 该缺口不是噪声极限（数据物理天花板 R² ≥ 0.973，三估计子互验），是真模型误差：在本架构与本数据下，绝对幅度（峰）与波形细节（sine）不存在同坐点——架构级互斥，多轮参数战役坐实。
2. **参数不可跨细胞携带。** 九细胞交叉验证（固定全部 16 参、每细胞仅重解 GKr 单标度）：仅母细胞 16713003 过线（5/6），其余八细胞 1–4/6——参数集适用域 = 16713003 单细胞。跨细胞使用必须重新标定，且单标度 GKr 重标定不够（八细胞标度散布 0.42–2.15 仍不过半）。唯一跨细胞普遍幸存的是稳态量比（保持电流 9/9 过）。
3. **串行关闭态扩展（候选机制）经检验不可识别**：插一个串行关闭态存在过线点，但 Fisher 信息分析显示其速率乘子的 Cramér–Rao 界 ±9.6–13.2 dex，超出数据活性窗（±0.017 dex）约 760 倍——该方向参数不可由现有四协议定位，故未纳入模型。
4. 机制件均为文献部件重组（四态环 = F11 2011；双指数激活边 = Wang 2013 双电荷；慢尾 = 文献双指数去激活）；本工作贡献是 X 件的负电位门结构定型与定量标定、hrs 激活动力学锚、以及上述边界地图。
