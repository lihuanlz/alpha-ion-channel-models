# α-Ion-Channel Models

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23008848.svg)](https://doi.org/10.5281/zenodo.23008848)

Mechanism-anchored, data-extracted kinetic parameters for five cardiac ion channels
(hERG/I_Kr, Nav1.5/I_Na, CaV1.2/I_CaL, I_Ks/KCNQ1+KCNE1, Kv4.3/I_to), with
cross-laboratory validation and ORd host-model integration / CiPA drug scoring.

This repository is the code-and-data companion of the manuscript
*Nature_main_v05* (see `01_manuscript/`).

## Method in one paragraph

Instead of fitting phenomenological model parameters, we extract kinetic
quantities directly from voltage-clamp recordings under pre-registered
extraction rules, validate them by forward re-simulation against held-out
protocols, and anchor them to independent physical measurements (VCF
fluorescence components, allosteric rate constants). Cross-laboratory
replication covers hERG (9 + 19 cells, two labs), Nav1.5, CaV1.2 (control and
pharmacology arms), I_Ks (WT + drug arms), and a registration-grade probe on
Kv4.3. Extracted I_Kr/I_Ks were substituted into the ORd human ventricular
model (APD90 difference 0.36%) and scored against CiPA drug data under a
dynamic-binding criterion.

## Reproduce

Python 3.11+, see `04_code/README` per subfolder. Figures are regenerated by
the `09_figures/` scripts (PNG + SVG output). A full local-machine re-run
ledger reconciled against the sealed verdict values is in
`REPRODUCIBILITY.md` (StageB chain re-run 2026-09-27/28, identifiability
chain 2026-09-26; all key statistics reproduced).
